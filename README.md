# UNIPAMPA - RP II 2024.2

Projeto acadêmico em grupo desenvolvido na disciplina de **Resolução de Problemas II**, no curso de Engenharia de Software da UNIPAMPA.

O projeto teve como foco a aplicação de conceitos de **programação orientada a objetos**, **testes unitários**, **testes de integração** e evolução incremental de uma solução em Java.

---

## 📌 Sobre o projeto

Este repositório reúne versões evolutivas de uma aplicação desenvolvida em Java para simular o funcionamento de uma máquina/dispenser, incluindo componentes como controle, display, teclado, entrada de dados e dispenser de bebidas/dinheiro.

A estrutura do repositório foi organizada em diferentes versões do código, permitindo acompanhar a evolução da solução ao longo da disciplina.

---

## 🎯 Objetivos

- Aplicar conceitos de programação orientada a objetos
- Separar responsabilidades entre classes
- Implementar testes unitários
- Implementar testes de integração
- Evoluir o código em versões incrementais
- Praticar colaboração com Git/GitLab
- Documentar a evolução do projeto acadêmico

---

## 🧩 Funcionalidades e componentes
